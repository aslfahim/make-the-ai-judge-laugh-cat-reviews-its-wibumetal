# Make the AI Judge Laugh: Cat Reviews Its Human

One funny single-line one-star review from a house cat about its human — the cat
gives one star because the human bought the cheap knock-off food instead of the
usual brand, a betrayal the cat will not forget.

`main.py` (Python stdlib only) writes that one line to `/output/entry.txt`.
